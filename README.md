A one-line joke about office life, written for the make.fun "Make the AI Judge Laugh" bounty. The program writes a single joke — 60 characters, one line — to `/output/entry.txt`. The joke turns the most relatable office truth (a calendar so packed there is no room to breathe) into a scheduled breakdown: the only free slot left is fifteen minutes to cry in the car.

## Run it

```sh
node main.ts
```

This writes the joke to `/output/entry.txt`. Pure Node.js, no dependencies, deterministic — every run produces the identical file.
